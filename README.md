# PEP lab「コミュニティドリブン就活」LP

データベースを使わない、HTML・CSS・JavaScriptだけのシンプルな静的サイトです。

## フォルダ構成

```
├── index.html          … ページ本体（文章の変更はここ）
├── css/style.css       … デザイン（色は先頭の :root で変更）
├── js/config.js        … LINE登録URL・InstagramのURLの設定
├── js/communities.js   … ★コミュニティ・イベント情報（ここを更新して掲載）
├── js/main.js          … 表示の仕組み（通常は編集不要）
└── images/             … 画像（logo.png は正式ロゴ、*-placeholder.svg は仮画像）
```

## ローカルで表示する

`index.html` をダブルクリックすると、ブラウザで開けます。

## よくある作業

### コミュニティやイベントを掲載する
`js/communities.js` を開きます。ファイル冒頭の「ひな形」をコピーし、`window.COMMUNITIES = [ ]` の中に貼り付けて書き換えてください。HTMLを触る必要はありません。

- 上に書いたコミュニティほど、ページの上に表示されます
- `isNew: true` にすると「NEW」マークが付きます
- イベントの `url` を空（`""`）にすると、申し込みボタンの代わりにLINE登録ボタンが表示されます
- 1件も登録がないときは、「準備中」のカードが表示されます
- 保存したら必ずブラウザで表示を確認してください。何も表示されなくなったら、`,`（カンマ）や `"` の抜けがないか確認します

**GitHubの画面で編集する場合：** ファイルを開き、右上の鉛筆マークで編集して、**Commit changes** を押すと保存されます。

### LINE登録URL・InstagramのURLを変える
`js/config.js` の `lineUrl` を書き換えます。Instagramのリンクは同じファイルの `instagramUrl` で変更できます（空にするとリンクが非表示になります）。

### 画像を差し替える
`images/` に新しい画像を入れ、`index.html` の `src="images/〇〇"` の部分を、そのファイル名に変更します。`alt`（画像の説明文）も一緒に書き換えてください。コミュニティの画像は、`js/communities.js` の `image` に書きます。

## 公開前に確認が必要な項目

`index.html` で「要確認」と検索すると、該当箇所が見つかります。

- [x] LINE登録URL
- [x] 参加費（FAQ）
- [x] 運営者情報のリンク（https://peplab.jp/）
- [x] ロゴ
- [ ] 3つの特徴・参加の流れの文言の最終確認
- [ ] 仮画像（hero / about / event）の差し替え
- [ ] 公開URLが決まったら、OGP（`og:url`、`og:image`）を設定
- [ ] アクセス解析（Googleアナリティクスなど）やフォームを追加する場合は、プライバシーポリシーを用意する

※実績・数値・参加者の声・イベントの日程は、事実確認ができたものだけを載せてください。
