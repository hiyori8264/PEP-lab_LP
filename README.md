# PEP lab「コミュニティドリブン就活」LP

データベースを使わない、HTML・CSS・JavaScriptだけのシンプルな静的サイトです。

## フォルダ構成

```
pep-lab-lp/
├── index.html        … ページ本体（文章の変更はここ）
├── css/style.css     … デザイン（色は先頭の :root で変更）
├── js/config.js      … ★LINE登録URLの設定
├── js/main.js        … ボタンの動作など（通常は編集不要）
└── images/           … 画像（現在は仮画像）
```

## ローカルで表示する

`index.html` をブラウザにドラッグ＆ドロップするか、ダブルクリックで開くだけで表示できます。

## よくある作業

### LINE登録URLを設定する
`js/config.js` を開き、`lineUrl: ""` の `""` の中にURLを入れて保存します。
ページ内のすべてのLINEボタンにまとめて反映されます。URLが空のままだとボタンを押したときに「準備中」と表示されます。

### 画像を差し替える
`images/` に新しい画像を入れ、`index.html` の `src="images/〇〇"` の部分をそのファイル名に変更します。`alt`（画像の説明文）も一緒に書き換えてください。

### イベントを追加する
`index.html` の「イベント紹介」セクションに、コメントアウトされた**ひな形**があります。`<!--` と `-->` の間をコピーして、コメントの外に貼り付けてから内容を書き換えてください。イベントを掲載したら「準備中」カードは削除します。

## 公開前に確認が必要な項目

`index.html` で「要確認」と検索すると、該当箇所が見つかります。

- [ ] LINE登録URL（`js/config.js`）
- [ ] 3つの特徴の文言（コンセプトをもとにした案です）
- [ ] 参加の流れ（実際の手順と合っているか）
- [ ] FAQの回答（特に参加費の有無）
- [ ] フッターの「運営者情報」「プライバシーポリシー」のリンク先
- [ ] 仮画像・仮ロゴ（`images/logo.svg`）を正式なものに差し替え
- [ ] 公開URLが決まったら OGP（`og:url`、`og:image`）を設定

※ 実績・数値・参加者の声・イベントの日程は、事実確認ができたものだけを載せてください。
